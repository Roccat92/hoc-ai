# Phần 2: Code với AI

Bắt đầu làm ra sản phẩm thật. Cài một coding agent (Claude Code hoặc Codex), biết các AI IDE khác để chọn cho hợp, build một web app hoàn chỉnh chỉ bằng mô tả tiếng Việt, học debug/test/review, lưu công sức lên GitHub, và hiểu rõ công cụ mình đang cầm.

**Dành cho:** người đã xong [Phần 1](../01-bat-dau-tu-so-0/). **Học xong:** có một ứng dụng chạy thật do chính bạn "chỉ đạo" AI làm ra, hiểu đại khái nó hoạt động thế nào, và code đã nằm an toàn trên GitHub.

Lộ trình dưới đây viết chung cho mọi coding agent, không thiên vị Claude Code hay Codex - xài AI nào là lựa chọn của bạn. Chi tiết riêng từng công cụ (lệnh cài chính xác, bảng giá VND, cấu hình quyền/MCP nâng cao) nằm ở [phụ lục: hướng dẫn theo công cụ](../phu-luc-cong-cu/), đọc khi cần tra cứu, không bắt buộc.
