# Phần 2: Code với AI

Bắt đầu làm ra sản phẩm thật. Cài Claude Code và Codex, biết các AI IDE khác để chọn cho hợp, build một web app hoàn chỉnh chỉ bằng mô tả tiếng Việt, học debug/test/review, lưu công sức lên GitHub, và hiểu rõ công cụ mình đang cầm - chọn đúng chỗ làm việc và trả tiền đúng gói.

**Dành cho:** người đã xong [Phần 1](../01-bat-dau-tu-so-0/). **Học xong:** có một ứng dụng chạy thật do chính bạn "chỉ đạo" AI làm ra, hiểu đại khái nó hoạt động thế nào, và code đã nằm an toàn trên GitHub.
