# Nhà Sạch Xinh - Landing page

## Quy ước chung
- Ngôn ngữ giao tiếp: tiếng Việt
- HTML/CSS/JavaScript thuần - không dùng framework, không cần bước build, chạy được bằng cách mở file trực tiếp trong trình duyệt hoặc dùng live server đơn giản
- Ưu tiên code dễ đọc; với phần JavaScript xử lý form, comment ngắn gọn giải thích từng bước

## Cấu trúc thư mục
- `index.html` - toàn bộ nội dung trang
- `style.css` - style riêng, tách khỏi HTML để dễ đọc
- `script.js` - xử lý gửi form (nếu cần JavaScript ngoài HTML thuần)

## Điều cấm làm
- Không tự thêm framework hay thư viện ngoài dự tính (nếu thấy cần, hỏi trước khi cài)
- Không tự đổi dịch vụ gửi form (Formspree) sang cách khác nếu chưa hỏi

## Lưu ý riêng của dự án
- Luôn đọc `spec.md` và `backlog.md` trước khi bắt đầu một task mới
- Đây là dự án học tập theo mẫu - ưu tiên giải thích ngắn gọn code đang làm gì, để người học hiểu chứ không chỉ chạy được
- Số liệu giá trong spec.md là ví dụ minh họa, không cần chính xác tuyệt đối
