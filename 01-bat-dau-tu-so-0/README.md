# Phần 1: Bắt đầu từ số 0

Phần quan trọng nhất với người mới: tư duy học đúng cách trước khi cài bất cứ thứ gì, rồi cài môi trường, học ChatGPT từ prompt tới file/dữ liệu/Projects, và nắm mô hình web–API–database đủ để làm việc với AI. Làm đúng phần này, mọi phần sau sẽ nhẹ hơn rất nhiều.

**Dành cho:** người chưa từng mở terminal, chưa từng viết một dòng code. **Học xong:** máy tính đã sẵn sàng để code cùng AI, và bạn biết cách hỏi AI để học nhanh thay vì copy mù.
